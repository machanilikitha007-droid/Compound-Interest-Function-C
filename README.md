# Compound Interest Using Function in C

This program calculates compound interest using a user-defined function
that returns the final amount.

## File

compound_interest.c

## Concepts Used

- Function definition
- Function parameters
- Function call
- Return value
- for loop

## How to Run

gcc compound_interest.c -o compound_interest
./compound_interest

## Sample Output

Enter principal, rate and years: 10000 5 2
Compound Interest = 1025.00
Total Amount = 11025.00
